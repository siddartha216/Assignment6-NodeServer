# Assignment 6 - Simple Web Server

## Description
This project creates a simple web server using Node.js http module.

## Features
- Handles /home, /about, /contact routes
- Custom 404 page
- External CSS styling
- Asynchronous file handling using fs.readFile
- Proper HTTP status codes

## How to Run
1. Install Node.js
2. Run: node server.js
3. Open browser:
   - http://localhost:3000/home
   - http://localhost:3000/about
   - http://localhost:3000/contact
